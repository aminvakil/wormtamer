# Lessons Learned

Record only non-obvious findings established by a concrete bug, test, incident, or verified external behavior. Generic advice, design rationale, and chronological work logs do not belong here.

For each lesson, include:

- **Context:** what was attempted
- **Finding:** the non-obvious result
- **Evidence:** the test, issue, incident, or source
- **Action:** what future work should do differently

When a finding becomes a permanent rule, move it to architecture, reliability, or security. Runtime review memory is separate installation data and never belongs in this file.
